### 🏢 Current Project:

**iScope AI Assistant**: an assistant built into iScope so that supervisors and managers can ask questions about their projects in plain Arabic or English and get answers they can trust.

- 💬 **Ask in plain language**: questions about projects, contracts, visits and progress, answered from the real data.
-  **Reports with charts**: Excel and PDF reports with KPIs, bar, line, donut, heatmap, progress and waterfall charts. The server writes every number, so the model never invents them.
-  **Everyone sees only their own projects**: access rules are enforced by the server, not by the prompt.
-  **Team skills**: the iScope team writes playbooks (business analyst, data scientist, KPI dashboard design) that the assistant follows.
-  **Tested**: automated tests on invented data, plus a check that the tests really fail when the rules are broken.
-  **Built the micro way**: small leaf features, a critic review, replayable proof and a signed record.
